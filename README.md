# zotero-skill —— 你的 Zotero 文献综述一键生成器

> 一个连接 Zotero 桌面客户端与 AI 大模型的开源 Skill，让你一句话就能读完一个领域的全部论文。

---

## 一句话介绍

**「帮我整理总结一下 Zotero 中 XXX 栏所有的文献，并生成一个一万字的综述」**—— 这句话，现在真的可以被实现了。

---

## 为什么需要它？

做科研的你，一定经历过这些痛苦时刻：

- 某个文件夹里攒了几十上百篇论文，永远没有时间系统整理；
- 写综述时，对着一堆 PDF 发呆，不知道从何下手；
- Zotero 里的文献越积越多，但它们只是「躺在那里」，从未被真正「读过」。

**zotero-skill 就是为了解决这些问题而生。** 它直接连接你的 Zotero 本地数据库，让 AI 替你梳理文献、总结脉络、甚至输出万字综述。

---

## 它能做什么？

### 基础能力
- **连接 Zotero 本地 API**：无需上传、无需同步，直接读取你电脑上的 Zotero 库；
- **遍历指定收藏夹**：你说「人工智能」栏目，它就只读人工智能；
- **获取完整元数据**：标题、作者、摘要、发表时间、DOI、标签，一个不落；
- **定位本地 PDF**：自动找到 PDF 在硬盘上的存储路径，支持进一步全文分析。

### 进阶能力
- **批量文献总结**：一口气总结 75 篇论文的核心贡献、方法创新、实验结论；
- **主题分类归纳**：自动按研究方向（如目标检测、图像分割、热成像检测）归类整理；
- **综述大纲生成**：梳理领域发展脉络，提炼关键里程碑和前沿趋势；
- **万字长文输出**：基于全部文献信息，生成结构完整的学术综述文档。

---

## 技术亮点

| 特性 | 说明 |
|------|------|
| **纯 HTTP 直连** | 不依赖任何第三方库，curl / PowerShell 直接调用 Zotero Local API |
| **PDF 本地读取** | 自动定位 `%USERPROFILE%\Zotero\storage\` 下的 PDF 文件，支持 pdfplumber 全文提取 |
| **跨平台兼容** | Windows、macOS、Linux 均可使用，只要有 Zotero 桌面客户端 |
| **零配置上手** | 打开 Zotero → 勾选本地 API → 即可使用，无需 API Key |
| **隐私安全** | 所有数据读取都在本地完成，文献不上传云端 |

## 使用场景

- **文献综述写作**：半小时梳理一个收藏夹的全部论文，直接拿到综述初稿；
- **领域快速调研**：新进入一个研究方向，快速了解有哪些关键论文和方法；
- **组会汇报准备**：自动提取每篇论文的「一句话贡献」，做成 PPT 大纲；
- **论文引用管理**：批量导出 BibTeX，自动生成参考文献列表；
- **阅读优先级排序**：让 AI 根据你的研究方向，推荐最值得精读的几篇论文。

---

## 快速开始

1. 安装 Zotero 桌面客户端并打开；
2. 开启本地 API：`编辑 → 设置 → 高级 → 允许其他应用程序与 Zotero 通信`；
3. 安装 zotero-skill 到你的 AI 助手（如 Codex）；
4. 说一句话：「帮我总结人工智能栏目里的所有文献」；
5. 坐等万字综述自动生成。
